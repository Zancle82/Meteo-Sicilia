Meteo Sicilia beta 0.7 — test privato.

Novità: confronto a +6, +12, +24, +48, +72 ore; temperatura mediana e intervallo, vento mediano, numero di modelli che prevedono almeno 0,1 mm di pioggia nell’ora e accumulo orario mediano. Sintesi sperimentale non calibrata: non è una probabilità di pioggia né un prodotto validato.

Modelli: ECMWF IFS, AIFS, NOAA GFS, DWD ICON-EU, Météo-France ARPEGE, GEM e tentativo ItaliaMeteo ICON-2I (può non essere disponibile). API Open-Meteo per uso non commerciale.
