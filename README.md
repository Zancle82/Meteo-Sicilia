# Meteo Sicilia 0.5 — beta privata

Quattro schede: Previsioni, Stazioni, Modelli, Fonti. Mantiene grafici 0.4.3, Ecowitt San Giovannello e confronto ECMWF/GFS/ICON. La rete Meteo Sicilia e le fonti esterne sono per ora link di consultazione; nessuna importazione automatica di dati della rete.

Caricare i sei file nella radice del repository GitHub Pages, sostituendo quelli precedenti. I due file JS sono disponibili anche come TXT per il download da Android: rinominarli `app.js` e `sw.js` prima di caricarli.

Le API gratuite possono avere restrizioni per uso commerciale; prima di introdurre pubblicità verificare le licenze.
